# Checklist de validação antes da entrega

Use esta lista para testar o projeto no navegador. Marcar um item significa que você executou o teste, não apenas que leu o código.

## Estrutura e navegação

- [ ] Abrir `index.html` e visitar as seis páginas pelo menu.
- [ ] Verificar se o link ativo do menu indica a página atual.
- [ ] Pressionar Tab desde o início e observar os atalhos para conteúdo e navegação.
- [ ] Usar Tab e Shift+Tab para percorrer controles e links.
- [ ] Confirmar que o foco tem contorno visível.
- [ ] Abrir o menu em largura móvel e testar o fechamento com Escape.
- [ ] Confirmar que todos os links internos abrem a página correta.

## Conteúdo e percepção

- [ ] Conferir se cada página possui um `h1`.
- [ ] Conferir a ordem dos títulos e subtítulos.
- [ ] Verificar se as imagens informativas têm texto alternativo.
- [ ] Verificar se nenhum significado depende exclusivamente da cor.
- [ ] Aumentar o zoom do navegador para 200% e conferir se não há rolagem horizontal desnecessária.
- [ ] Testar os botões A+, A− e Alto contraste.
- [ ] Testar a leitura por voz, se o navegador oferecer suporte.

## Responsividade e código

- [ ] Testar em uma tela estreita ou no modo responsivo do navegador.
- [ ] Testar sem JavaScript: o conteúdo principal e links continuam disponíveis; os controles interativos deixam de funcionar.
- [ ] Conferir o console do navegador para erros JavaScript.
- [ ] Usar o validador HTML do W3C: https://validator.w3.org/ (opcional, mas recomendado).
- [ ] Usar o avaliador ASES: https://asesweb.governoeletronico.gov.br/ (quando disponível).
- [ ] Fazer avaliação manual; ferramentas automáticas não encontram todos os problemas.

## Entrega

- [ ] Manter todos os seis arquivos HTML e a pasta `assets`.
- [ ] Incluir o vídeo demonstrativo gravado (3 a 5 minutos) dentro da pasta do projeto.
- [ ] Publicar a pasta em um serviço de hospedagem estática e copiar o link real.
- [ ] Atualizar `LINK_PUBLICADO.txt` com o endereço verdadeiro.
- [ ] Compactar a pasta inteira em ZIP e enviar no AVA.
