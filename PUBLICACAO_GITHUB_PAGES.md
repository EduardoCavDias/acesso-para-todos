# Publicação no GitHub Pages

O projeto está publicado em um repositório público e estático:

- Repositório: https://github.com/EduardoCavDias/acesso-para-todos
- Site: https://eduardocavdias.github.io/acesso-para-todos/
- Branch de publicação: `main`
- Origem: `/(root)`

O GitHub Pages publica os arquivos diretamente da branch `main`. Para atualizar o site, envie as alterações para essa branch e aguarde a conclusão do workflow de deploy em **Actions**. O arquivo `index.html` deve permanecer na raiz do repositório.

Antes de entregar, abra o endereço publicado e confira a navegação, os links internos, as ilustrações e o carregamento do CSS e do JavaScript. O endereço também está registrado em `LINK_PUBLICADO.txt`.
